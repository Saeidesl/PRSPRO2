# IRANSansWeb font assets

Place the six user-provided WOFF2 files in this directory with these exact names:

- `IRANSansWeb.woff2` — Regular (400)
- `IRANSansWeb_UltraLight.woff2` — UltraLight (200)
- `IRANSansWeb_Light.woff2` — Light (300)
- `IRANSansWeb_Medium.woff2` — Medium (500)
- `IRANSansWeb_Bold.woff2` — Bold (700)
- `IRANSansWeb_Black.woff2` — Black (900)

The app loads these files through `css/fonts.css`. Keep filenames and casing unchanged.
