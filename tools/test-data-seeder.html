داده‌ساز آزمایشی نرم‌افزار مدیریت تولید

این ابزار با نشست ورود فعلی شما کار می‌کند و از API واقعی برنامه استفاده می‌کند. پروژه‌های آزمایشی با کدهای TEST-0001 تا TEST-0050 و رویدادهای مرتبط ساخته می‌شوند.

هشدار: این عملیات داده واقعی در پایگاه داده فعلی ایجاد می‌کند. فقط در محیط آزمایشی یا زمانی اجرا کنید که ساخت داده‌های تستی در محیط فعلی مورد تأیید شماست. رکوردهای موجود با کد TEST-0001 تا TEST-0050 دوباره ساخته نمی‌شوند.
